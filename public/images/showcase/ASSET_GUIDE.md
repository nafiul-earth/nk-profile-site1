# Showcase asset guide

Each leaf folder maps to one portfolio card in `src/data/aiShowcaseData.js`.

## Recommended contents

- **AI UGC:** final vertical video, poster frame, two or three supporting stills, and one hook or shot-list board.
- **AI Video:** final film, two or three still frames, and one storyboard or process image.
- **Character Design:** hero image, turnaround or consistency board, expression sheet, and one in-context scene.
- **Websites:** desktop screenshot, mobile screenshot, and one interface detail crop. Use screenshots of real working sites where available.
- **AI Automation:** hero workflow diagram, input view, human-checkpoint view, and output view.

## File naming

Use simple ordered names so gallery order remains intentional:

```text
cover.png
01-overview.png
02-detail.png
03-process.png
final-video.mp4
poster.jpg
```

Keep each project inside its matching folder. Media should remain marked `TO BE UPDATED` in the site until the exact files and their image-specific notes have been reviewed.
